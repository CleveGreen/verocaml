#+TITLE: Broadcast and Callback Outcome Coverage

This document describes grouped outcome coverage for scoped broadcasts,
verified callback traversals, verified callbacks, and first-class
specifications.  Ordinary cases use Dune-backed fixtures and select closed
status, code, function, unit, obligation, and parity facts.  Specialist checks
cover encoding, authentication, compiler, runtime, package, and bounded-resource
contracts.

No assertion in this group is a deliberate presentation contract, so the
group has no UI golden.

* Scoped Broadcasts

Host: ~test/scoped_broadcasts/outcome_cases.ml~

Focused alias:
~@test/scoped_broadcasts/scoped-broadcasts-outcome-check~

- ~function-valued-trigger-verifies~ selects verified status, its unit, and
  the selected function.
- ~parametric-source-cmt-thread-parity~ compares Dune source with a declared
  prepared CMT across execution modes, excluding only ~input-mode~ and
  ~execution-mode~.
- ~broadcast-group-verifies~, ~lexical-scopes-verify~, and
  ~trusted-and-ordinary-axioms-verify~ select verified units and their grouped,
  nested, or trusted consumer functions.
- ~declaration-and-alpha-order-parity~ compares declaration variants while
  excluding only ~source-variant~.
- ~inactive-broadcast-counterexample~ and ~e-matching-counterexample~ select
  counterexample status, keyed units, and assertion or postcondition kinds.

Specialist checks cover quantifier insertion, grouped and lexical activation,
trusted provenance, PPX carriers, private insertion identity, runtime erasure,
malformed PPX input, zero-work authentication boundaries, carrier attacks,
the fixed broadcast-instance cap, and source or install architecture.
~VERO_BROADCAST_AUTHENTICATION~ remains a real stable code for the applicable
corrupted-artifact boundary.

* Verified Callback Traversals

Host: ~test/verified_callback_traversals/outcome_cases.ml~

Focused alias:
~@test/verified_callback_traversals/verified-callback-traversals-outcome-check~

- ~quantifier-source-cmt-thread-parity~ selects verified quantifier functions
  and closed source/prepared/thread parity.
- ~quantified-postcondition-counterexamples~ selects counterexample status,
  keyed units, and postconditions for the false quantified functions.
- ~symbolic-quantifier-source-cmt-thread-parity~ selects the symbolic function
  set and closed mode parity.
- ~quantifier-statements-source-cmt-thread-parity~ selects proof and assertion
  functions plus closed mode parity.

Specialist checks cover fixed solver policy, binder and trigger encoding,
symbolic pattern heads, carrier and trigger attacks, private identity,
zero-work boundaries, cleanup, and hard timeout guards.
