#+TITLE: Frontend and Intermediate Representation Outcome Coverage

This ledger records the current testing boundary for specification frontend,
pure specification, SST, Logic IR, and checked-integer VIR suites.  Grouped
cases select the closed semantic projection.  Cram and tool checks cover private
representations, complete renders, compiler-surface boundaries, or explicit
resource behaviour.

No suite in this group uses an outcome resource maximum or mode-parity
exception.

* Specification Frontend

Host: ~test/specification_frontend/outcome_cases.ml~

Focused alias:
~@test/specification_frontend/specification-frontend-outcome-check~

- ~retained-contract-semantics~ selects verified status, the verified unit,
  function ~checked~, and assertion and postcondition obligation kinds.
- ~retained-assertion-counterexample~ selects counterexample status, the
  counterexample unit, and an assertion semantic fact for ~rejected~.

~test/ui_goldens/specification_frontend/diagnostics.t~ owns selected PPX
wording.  The suite's Cram/tool lane checks PPX erasure, erased runtime/CMT
behaviour, and retained metadata authentication.
