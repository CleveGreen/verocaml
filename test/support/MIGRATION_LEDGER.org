#+TITLE: Outcome Coverage Ledger

This ledger records the current test route for these grouped outcome suites.
It distinguishes closed semantic projections, presentation goldens, and
specialist checks that intentionally inspect internal or complete output.

A canonical case identity is
~<repository-relative-host-path>::<case-name>~.  The focused aliases below run
producer, report, archive, and validator rules without depending on incidental
rendering.

* Projection Notation

The coverage summaries use these public combinators:

- ~status(S)~ is ~Expectation.status Outcome.S~.
- ~code(C)~ is ~Expectation.require_frontend_code C~.
- ~semantic(F, K)~ is
  ~Expectation.require_semantic ~function_name:F K~.
- ~unit(U, D)~ is ~Expectation.require_unit U Outcome.D~.
- ~fact(N, V)~ is ~Expectation.require_named_fact N V~.
- ~process(P)~ is ~Expectation.require_process_fact P~.
- ~parity(E)~ is closed ~Outcome.semantic_parity~ with the named-fact keys in
  ~E~ excluded.

None of these projections selects prose, spans, generated identifiers, order,
complete reports, or exact counts.
